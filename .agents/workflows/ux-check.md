# UX 體驗與介面檢驗流程 (UX Check Workflow)

本工作流程定義了看板專案（Kanban App）在功能迭代、樣式更新或版本發布前，必須進行的使用者體驗（UX）、互動流暢度與可用性驗收清單。

---

## 檢驗目標

確保看板在不同裝置、瀏覽器環境下，皆具備直覺流暢的操作體驗、清晰的視覺反饋、友善的無障礙支援與可靠的資料持久性。

---

## 檢驗項目清單

### 1. 視覺層次與設計一致性 (Visual & Hierarchy)
- [ ] **主題色彩一致性**：整體介面是否維持暖色系基調（燕麥奶底色 `--bg-primary`、焦糖暖橘 `--accent`），無突兀色彩。
- [ ] **卡片標籤辨識度**：
  - [ ] 分類標籤（工作/生活）底色與圓點色彩是否正確對應。
  - [ ] 優先程度標籤（High/Medium/Low）是否依權重有明顯層級感。
  - [ ] 截止日期標籤（年/月/日）是否清晰；若為「今天或已過期」是否呈現醒目紅標。
- [ ] **文字閱讀對比度**：所有文字與背景色（特別是各類藥丸標籤）是否符合 WCAG AA 基礎閱讀對比要求。

---

### 2. 響應式與跨裝置適應 (Responsive Design)
- [ ] **手機窄螢幕 (375px ~ 430px)**：
  - [ ] 表單控制項（輸入框、新增按鈕、分類、優先度、截止日）是否順暢換行，無橫向破版或溢出。
  - [ ] 看板欄位是否可正常垂直堆疊或流暢滑動檢視。
- [ ] **平板與桌面寬螢幕 (768px ~ 1200px+)**：
  - [ ] 三欄式（To-do, Process, Done）是否整齊並排，欄位寬度等比平衡。
  - [ ] 頁面最大寬度限制（`max-width: 1080px`）與水平置中是否正常。

---

### 3. 表單互動與防呆設計 (Form & Input UX)
- [ ] **空白送出防呆**：未輸入任何任務文字點擊「新增」或按 `Enter`，應具備原生提示阻止送出。
- [ ] **鍵盤操作便利性**：
  - [ ] 輸入框內按 `Enter` 鍵即可直接送出任務。
  - [ ] 送出後輸入框應自動清空，並自動維持聚焦狀態（Focus），方便連續建立多筆任務。
- [ ] **可選截止日期欄位**：
  - [ ] 日期未選擇時可順利提交，卡片不顯示日期標籤。
  - [ ] 日期選擇後提交，表單內的日期欄位應正確隨之重設為空。

---

### 4. 任務狀態轉換與反饋 (Interaction & Transitions)
- [ ] **桌面端原生拖放 (HTML5 Drag & Drop)**：
  - [ ] 開始拖曳時，原卡片應有半透明/縮放反饋（`.dragging` 樣式）。
  - [ ] 滑鼠游標移入目標欄位時，目標放置區應有醒目的進駐高亮（`drag-over` 樣式）。
  - [ ] 放開後卡片平滑移入目標欄位，兩側欄位的計數標籤（Count）即時更新。
- [ ] **按鈕快捷移動 (Mobile & Keyboard Friendly)**：
  - [ ] `To-do` 欄位卡片具備 `進行中 →` 按鈕，點擊後平穩轉入 `Process`。
  - [ ] `Process` 欄位卡片具備 `← 待辦` 與 `完成 →` 按鈕。
  - [ ] `Done` 欄位卡片具備 `← 重啟進行` 按鈕，且任務文字自動帶刪除線（Line-through）。
- [ ] **刪除與歸檔**：
  - [ ] 單張卡片點擊垃圾桶圖示可立即刪除，並具備懸停變紅警示（Hover State）。
  - [ ] `Done` 欄位若有卡片，標題旁自動顯示「清除」按鈕；點擊後一鍵歸檔完成項目。

---

### 5. 分類篩選體驗 (Filtering)
- [ ] 點擊頂部「全部」、「工作」、「生活」頁籤，卡片能即刻精準過濾，無閃爍或白畫面。
- [ ] 篩選狀態下新增相應分類之任務，頁籤與畫面應維持合理視圖。
- [ ] 頂部總計計數 pill（如「共 X 項任務」）應即時反映當前篩選下的任務總數。

---

### 6. 資料持久化與容錯驗證 (Data Persistence)
- [ ] **重新整理維持狀態**：按 `F5` 或重開瀏覽器分頁，所有已建立卡片、狀態欄位、截止日期標籤完整保留。
- [ ] **無舊資料報錯**：清除瀏覽器快取或載入舊版 localStorage key 時，程式碼自動相容預設值，控制台無 Runtime Error。

---

## 驗收確認方式

當上述所有核選項目均驗證通過後，在 Commit 訊息中備註通過 UX 檢查：
```bash
git commit -m "feat(或 fix): 調整項目說明 (通過 UX 檢驗)"
```
